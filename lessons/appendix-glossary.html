第 1 章 · ROS 2 是什么

缩写 / 术语 全称 意思
ROS Robot Operating System 机器人 / 操作 / 系统。名字叫操作系统，其实是装在 Linux 上的一套通信库和工具
node — 节点：只干一件事的程序
topic — 话题：有名字的数据通道，发布 / 订阅
service — 服务：一问一答
action — 动作：长任务，有反馈、能取消
parameter — 参数：节点自己的设置
DDS Data Distribution Service 数据 / 分发 / 服务：工业标准的发布订阅中间件，ROS 2 默认底层
RTPS Real-Time Publish-Subscribe 实时 / 发布 / 订阅：DDS 在网络上用的线上协议
RMW ROS MiddleWare ROS 中间件接口："插座"
rcl ROS Client Library ROS 客户端库的 C 语言核心
rclpy / rclcpp rcl + Python / C++ Python 版、C++ 版客户端库
QoS Quality of Service 服务 / 质量：可靠性、队列深度等通信设置
API Application Programming Interface 应用 / 编程 / 接口
UDP User Datagram Protocol 用户 / 数据报 / 协议：不保证送达的网络传输协议
IDL Interface Definition Language 接口 / 定义 / 语言
rosidl ROS IDL 把 .msg / .srv / .action 生成各语言代码的工具链
executor — 执行器：在 spin() 里查有没有新数据、再调用回调的调度器
wait set — 等待集：executor 用来询问"哪些队列有数据"的一组标志
VLA Vision-Language-Action 视觉 / 语言 / 动作模型
IK Inverse Kinematics 逆 / 运动学：由末端位置反算关节角
LTS Long-Term Support 长期支持版（ROS 2 的 LTS 支持 5 年）
EOL End Of Life 生命周期结束，不再维护
master — ROS 1 的中心登记进程（roscore），ROS 2 已取消
JSON JavaScript Object Notation JavaScript / 对象 / 表示法：一种文本数据格式；代码对照里用它代替 CDR 演示序列化
CDR Common Data Representation 通用 / 数据 / 表示：DDS 默认的二进制序列化格式（第 3 章 bag 里也会看到）

第 7 章 · QoS

缩写 / 术语 全称 意思
QoS profile — QoS 配置：一组策略的组合
History / Depth — 历史 / 深度：没处理完的消息留多少
Reliable / Best effort — 可靠（丢了重传）/ 尽力而为（丢了就丢）
Volatile / Transient local — 不保存 / 发布者保存最近消息给晚来的订阅者
Deadline / Lifespan — 截止时间（相邻消息最大间隔）/ 寿命（消息多久过期）
Liveliness / Lease duration — 活性 / 租期：多久不报平安算挂了
latched — 锁存：ROS 1 里"晚来也能收到最后一条"的话题，≈ Transient local
TCP Transmission Control Protocol 传输 / 控制 / 协议：保证送达、按序
Sensor data profile — 传感器预设：Best effort + 小队列
QoS event — QoS 事件：deadline missed、incompatible QoS 等，可挂回调

缩写 / 术语 全称 意思
action chunk — 动作块：模型一次输出的未来若干步动作
temporal ensembling — 时间集成：同一时刻多个块的动作加权平均（ACT）
RTC Real-Time Chunking 实时分块：边执行上一块边推理下一块，衔接不抖
message_filters — 按时间戳同步多个话题的工具
cv_bridge — ROS 图像消息与 OpenCV / numpy 互转
allow_trajectory_replacement — JTC 参数：新轨迹与执行中轨迹融合
positions_upsampling — JTC 参数：为只有位置的路点补出平滑速度
cartesian_trajectory_controller — 接收末端位姿轨迹的控制器（2026 新增）
jerk — 加加速度：加速度的变化率，越小越平稳
p99 99th percentile 第 99 百分位：100 次里最慢那一档
Hz Hertz 赫兹：每秒次数
