动画演示

每章关键原理配一个可单步的动画。讲义 md 里嵌的是 GIF（GitHub、Markdown 预览和 Mac 备忘录都能直接播放）；同名 .html 是交互版，可播放、单步、重来。

在 Claude 内置浏览器里看交互版：直接打开文件只显示静态快照，要先启动 .claude/launch.json 里的 ros2-animations 预览（或在仓库根目录 python3 -m http.server 8340 --directory ros2/notes/animations），再打开 http://localhost:8340/<文件名>.html。用 Chrome / Safari 直接双击 html 也可以。

新增或修改一个动画

  1. 第 1、2 章的页面是手写的；第 3 章起统一用本目录的 stepper.js：页面引用 anim.css、anim.js、stepper.js，调用 STEPPER({h, term, boxes, arrows, steps}) 只填数据（框、箭头、每一步高亮哪些、三行说明、终端输出）。
  2. 重新录 GIF（在本目录下执行）：

bash node ../../../tools/anim-capture/capture.mjs 07-qos-matching.html 07-qos-matching.gif 2200

录完会多出一个 *-last.png（最后一帧），检查排版后删掉即可。 3. 讲义"总图"一节嵌 ` 并给交互版链接；跑python3 tools/gallery/build.py更新画廊，tools/notes-sync/sync.sh ros2 "ROS 2"` 同步备忘录。
